# Worked example: URL shortener

An **illustrative** AI-DLC project frozen mid-flight: G1 to G3 approved, M1 and M2 done, M3 in progress.

- `docs/aidlc/` holds the artifacts a real run produces
- `.aidlc/` holds the real state and hash-chained audit log, generated by `aidlc.py`
- Verify it: `python scripts/aidlc.py --root examples/url-shortener verify`

The code, test runs and numbers in the reports are **invented for illustration**: there is no
shortener source in this repo. The point is the shape of the artifacts and the audit trail.
