# Milestone report: M1 Application foundation

<!-- Gate G4. Filled in by the agent; every claim needs evidence. -->

## Summary
Milestone M1 establishes the application foundation and first runnable vertical slice for Dependency Upgrade Assistant 2.0. The FastAPI backend has been implemented with centralized Pydantic settings, restricted development CORS, an explicit SQLite persistence foundation with WAL mode and foreign key enforcement, and a live health check endpoint probing database connectivity. The React + TypeScript frontend has been scaffolded with Vite, featuring a typed API client, accessible status cards with responsive loading/success/error states, and a reverse proxy configuration. Both servers were verified running independently and communicating directly, supported by 8 new backend unit tests, 5 new frontend Vitest tests, and 100% green execution across all 246 pre-existing baseline tests.

## Changes
- `pyproject.toml`: Added backend dependencies (`fastapi`, `pydantic`, `pydantic-settings`, `uvicorn`, `python-multipart`, `httpx`).
- `.env.example`: Created configuration template with safe defaults.
- `src/api/__init__.py`: Initialized FastAPI backend package.
- `src/api/config.py`: Implemented centralized Pydantic BaseSettings management with `.env` support.
- `src/api/database.py`: Implemented SQLite connection management, pragmas (WAL, foreign keys, busy timeout), schema initialization (`repositories`, `analysis_runs`, `pending_cleanups`), and live connectivity probes.
- `src/api/routes/health.py`: Implemented structured `GET /api/health` endpoint with live database probing.
- `src/api/main.py`: Created FastAPI application factory with metadata, CORS middleware, lifespan database initialization, and error handling.
- `tests/test_api_health.py`: Created 8 comprehensive backend unit tests covering config, database, health responses, and CORS.
- `frontend/`: Scaffolded React 19 + TypeScript frontend with Vite, Vitest test suite, centralized API client (`frontend/src/api/client.ts`), and `BackendStatus` component.

## Lens review
- Architecture: Decoupled FastAPI and React architecture established without modifying or degrading the existing Streamlit prototype in `src/app.py`.
- Security: CORS restricted to local development origins (`http://localhost:5173`, `http://127.0.0.1:5173`, etc.); no hardcoded credentials; database parameters sanitized.
- QA: Both backend and frontend have automated test suites testing both success and failure/degraded modes; full regression suite remains 100% green.
- UX: Developer console interface provides clear visual status badges, actionable error messages with troubleshooting hints, and responsive loading indicators.

## Known limitations
- M1 provides the foundational architecture and health communication slice only; manifest ingestion, dependency recommendations, sandboxed testing, and artifact export belong to subsequent milestones.
- Live Docker daemon and Ollama daemon are currently not running on this host workstation; M5 will implement truthful `NOT_RUNNABLE` reporting and M3 will implement deterministic fallback recommendations as designed in G3.
