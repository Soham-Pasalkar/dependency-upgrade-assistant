# Milestone report: M6 Artifact export

## Summary
Milestone M6 delivers the cryptographic artifact export and pre-export secret verification engine for Dependency Upgrade Assistant 2.0. The export service synthesizes production-ready unified Git patches, structured JSON execution summaries, sanitized execution console logs, and cryptographic SHA-256 manifests bundled into verified ZIP archives. A dedicated pre-export secret scanner enforces a zero-credential leakage policy by detecting API keys, private keys, and tokens with fail-closed semantics. The FastAPI backend exposes download endpoints with streaming file delivery, attachment headers, and server-authoritative SHA-256 headers, backed by a responsive React ExportManager component.

## Changes
- `src/services/secret_scanner.py`: Pre-export credential scanner with high-precision regex detection, secret masking, log sanitization, and fail-closed `SecretLeakageError`.
- `src/models/export.py`: Pydantic v2 schemas for `ArtifactType`, `ExportRequest`, `ExportItemMetadata`, and `ExportMetadataResponse`.
- `src/models/__init__.py`: Exposed M6 export schemas in models package namespace.
- `src/services/exporter.py`: Extended `ArtifactExporter` with `export_proposal`, `get_export`, and `get_artifact_file`, computing server-authoritative SHA-256 digests, generating unified patches and JSON summaries, testing ZIP archives via `testzip()`, and fail-closed staging cleanup.
- `src/api/routes/export.py`: REST endpoints for `POST /api/export`, `GET /api/export/{export_id}`, and streaming download routes with `X-Checksum-SHA256` headers and path-traversal guards.
- `src/api/main.py`: Registered export router under `/api` and `/api/v1`.
- `frontend/src/api/client.ts`: TypeScript export interfaces, API functions (`createExport`, `getExportMetadata`), and download URL generator.
- `frontend/src/components/ExportManager.tsx`: React component for export bundle generation, SHA-256 badge display, one-click hash copying, and deliverable downloading.
- `frontend/src/components/SandboxValidation.tsx`: Integrated `ExportManager` below validation logs.
- `frontend/src/App.css`: Accessible high-density styling for deliverables table, badges, and download controls.
- `tests/test_secret_scanner.py`: 10 unit tests for credential detection, masking, log redaction, and `verify_zero_secrets`.
- `tests/test_export_service.py`: 5 integration tests for proposal export, ZIP verification, path-traversal rejection, and fail-closed secret leakage handling.
- `tests/test_export_api.py`: 11 API integration tests covering creation, metadata lookup, file downloads, checksum headers, 404/422 error handling, and `/api/v1` parity.
- `frontend/src/components/ExportManager.test.tsx`: 5 frontend tests covering button states, status badges, download links, and clipboard copy.

## Lens review
- Architecture: Export coordination remains strictly separated between domain models, export service, and thin API controllers. Checksums are computed server-side from bytes written to disk.
- Security: Zero-credential leakage policy strictly enforced prior to file bundling. Staging directories are private (`0o700`) and wiped immediately on error (fail-closed). Path traversal in export IDs and artifact paths is strictly prevented via regex and `is_safe_relative_path`.
- QA: 34 focused backend tests and 5 frontend tests verify all acceptance criteria, error conditions, zip integrity, and header delivery with 100% pass rate.
- UX: Developer-first high-density table displays file sizes, SHA-256 badges, copy-to-clipboard buttons, and explicit download links with WCAG AA compliance.

## Known limitations
- Export bundles are stored in ephemeral server storage with automatic memory caching; persistent SQLite metadata tracking will be unified in M7/M8.
